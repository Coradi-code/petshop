# petshop
Para a fase 1 do Projeto da Disciplina de Fundamentos de Sistemas Web
Nesta etapa, foi elaborado um documento contendo:
A estrutura básica do sistema web, desta etapa
• Cabeçalho (header): com informações do petshop, links de navegação para as páginas, etc.
• Corpo das páginas (body): Visualização de dois produtos de cada uma das 3 categorias (foto, descrição, valor) e os serviços oferecidos pelo petshop (descrição, valor).
• Rodapé (footer): contendo informações legais de autoria, contato, links de navegação.
Para a realização desta etapa, o material consultado foi ate a aula 5, assim como como o uso de AI para criação de imagens e debug de código.
